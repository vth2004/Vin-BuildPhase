# Sandbox Kiểm chứng Multi-Model Pose Estimation

Mục tiêu: Đánh giá thực nghiệm các giả thuyết H1, H2, H3, H4 về việc bổ sung model vào ensemble Landmark QA.
Toàn bộ mã nguồn, dữ liệu cache, model weights và báo cáo nằm cô lập tại thư mục `experiments/model_check/`.
Không can thiệp vào mã nguồn hay database của production (`backend/`).
